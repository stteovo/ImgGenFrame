# 实现细节
本次查证的重大裁决（OFFICIAL-CKPT）：
① Table 2 的 32 heads 确认为笔误，真实 30（代码断言 head_dim==sum(axes_dims)，128=32+48+48）；
② Flux VAE 实锤（flux-dev，scaling 0.3611，repo 里的 0.18215 是禁用死代码）；
③ 推理不用动态 shift——base 固定 6.0、Turbo 固定 3.0；
④ adaLN 只由 timestep 驱动，文本走 token 流进序列；
⑤ 采样 sigma 表是 Z-Image 特有的 linspace(1, 1/N, N)。

1. 最核心的 10 个技术点
 1. 单流 S3-DiT：三类 token 拼一条流、逐层全交互——参数效率的来源（§4.1）
 2. 3D Unified RoPE：空间轴给图像、时间轴给文本，编辑时参考/目标共享空间、时间错位（§4.1）
 3. 低秩 adaLN：共享 down-proj + 每层 up-proj，把调制参数从 O(L·dim²) 压到 O(L·dim·256)（§4.1）
 4. 稳定性三件套：QK-Norm + Sandwich-Norm + 全 RMSNorm（§4.1）
 5. Flow Matching + velocity 预测：x_t=t·x₁+(1−t)·x₀，v=x₁−x₀（§4.3 公式 1）
 6. logit-normal t 采样 + 动态 shift：中间 t 集中 + 多分辨率 SNR 补偿（§4.3）
 7. 序列长度感知组 batch：按分辨率分组、长短序列动态 batch，多分辨率训练的效率关键（§4.2）
 8. 数据基建四模块：k-NN+Leiden 语义去重、知识图谱 BM25+层级加权采样（§2）
 9. Z-Captioner OCR-first：OCR 信息进 caption 与文字渲染能力直接绑定（§3.1）
10. Decoupled-DMD：CA 作引擎、DM 作正则的 8 步蒸馏（§4.5，细节在 2511.22677）

2. 最值得你亲自实现（学习价值 = 科学价值，且官方无训练代码可抄）
- RoPE / 低秩 adaLN / Sandwich-Norm 块 / FM 目标 + 动态 shift：这是 S3-DiT 的"科研心脏"，每一个都有可验证的数学性质
- 训练循环 + 组 batch + SFT 三技术（narrowing/balancing/merging）：论文只有思想没有参数，全要靠你的缩比消融定参数——这是本项目最大的原创空间
- 数据管线方法论（去重/图谱采样/caption 模板）：可迁移到任何后续研究

4. 最容易出错的地方（按杀伤力排序）
1. heads 抄 32 → head_dim 错 → RoPE 维度错（用 30）
2. VAE 缩放用 0.18215 → latent 分布偏移，训练发散（用 0.3611/0.1159）
3. shift 口径混用：训练动态（0.5→1.15）/ base 推理 6.0 / Turbo 3.0，三个口径必须显式区分
4. adaLN 把文本也塞进去——官方只由 t 驱动，文本是 token 流里的成员
5. 采样用标准 Euler sigma 表——Z-Image 是 linspace(1, 1/N, N)，不照抄会破坏 8 步 Turbo 的行为
6. RoPE 时间轴偏移：text 从 0 起、image 从 cap_len+1 起，编辑双条件逐 token 选择
7. 把 SD3/Flux 的 lr/EMA 当论文值——论文全文没有这些数字（open_questions A 表 14 项全是 UNKNOWN）
8. 给 Turbo 设 guidance>0 / 给 base 设 guidance=0，与官方行为不符

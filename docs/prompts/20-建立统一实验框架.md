使用 experiment skill。

现在建立统一 experiment framework。

每个 experiment 自动记录：

experiment_id
git_commit
timestamp
config
environment
GPU
CUDA
PyTorch
dataset_version
model_version
seed

输出：

experiments/<id>/

config.yaml
metrics.json
stdout.log
samples/
checkpoints/
report.md

实现：

scripts/train.py

要求：

任何实验必须可以：

python train.py --config configs/xxx.yaml

恢复：

--resume checkpoint

不要让训练参数散落在 Python source code。
